📋 Setup Checklist

Manual steps in order for walking through the demo yourself:

  • ☐ 1. Go to the onboarding page and sign up as a new company (“Fresh Cart Co.”)
  • ☐ 2. Copy the private key shown once at signup — save it somewhere safe, it won't be shown again
  • ☐ 3. Copy the public key shown at signup
  • ☐ 4. Paste the public key into CONFIG.publicKey in this file's source (or, if a settings UI exists, into the settings drawer below)
  • ☐ 5. Use the private key to upload the Instacart dataset through the onboarding upload flow
  • ☐ 6. Wait for training (or use the popular-products fallback shown here in the meantime)
  • ☐ 7. Refresh this page — the fallback badge should disappear once training completes
Note: Each checklist item is plain static text, not functional — this is a reminder panel for walking through the demo yourself, not a wizard.
